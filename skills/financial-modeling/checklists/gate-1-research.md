# Gate 1: Layer 1 Research Completeness

**Trigger**: After completing Layer 1 diagnostics and 8D research.

## Checklist

- [ ] **8D Framework Complete**
  - [ ] Market Size (TAM/SAM/SOM with sources + dates)
  - [ ] Growth Rate (historical + projected with supporting data)
  - [ ] Customer Economics (CAC, LTV, payback period if applicable)
  - [ ] Competitive Position (market share, key competitors)
  - [ ] Regulatory/ESG Risks (material risks + response measures)
  - [ ] Technology/Product Roadmap (near-term milestones)
  - [ ] Management Quality (team depth, relevant experience)
  - [ ] Financial Health (net cash position, leverage, cash flow quality)

- [ ] **Net Cash Calculation Verified**
  - Formula: Cash + ST Investments - ALL Interest-bearing Debt
  - NOT: Total Current Assets - Total Current Liabilities (wrong!)
  - NOT: Ignoring short-term portion of long-term debt (inflates net cash)

- [ ] **Each Target Question Has**
  - Historical data anchor
  - Industry peer view
  - 3-Scenario table (Bear / Base / Bull)

- [ ] **Revenue/Investment Cycle Diagnosed**
  - Seasonality patterns identified
  - CapEx timing understood (lumpy vs smooth)
  - Working capital patterns documented (AR/Inventory/AP days)

- [ ] **Leading Indicators Identified**
  - SaaS: ARR, Churn Rate, CAC Payback
  - Hardware: Unit shipments, ASP trend, channel mix
  - Marketplace: GMV, take rate, buyer/seller growth

**Pass**: All items checked with quantitative support and sources.
