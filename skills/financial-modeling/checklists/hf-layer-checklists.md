# HF Track: Layer-by-Layer Checklists

## Layer 0 — Investment Thesis
- [ ] Core conviction stated in one clear sentence
- [ ] vs consensus delta > 5%
- [ ] Catalyst date and trigger specified
- [ ] Expected Value > 5% (worth trading)
- [ ] Stop-loss condition defined (hard / soft / time)

## Layer 1 — Research & Divergence
- [ ] Consensus data confirmed (Bloomberg/FactSet/sell-side)
- [ ] Divergence map complete (3-5 dimensions)
- [ ] Falsification conditions listed (3-4 binary triggers)
- [ ] Thesis Validation Statement filled (supported / partial / opposed)
- [ ] EV and asymmetry ratio calculated

## Layer 2 — Single-Factor Sensitivity
- [ ] Core Variable sensitivity P10-P90 range
- [ ] Best vs worst case return spread > 30pp
- [ ] Asymmetry ratio > 1.5x (quality threshold)
- [ ] Position size aligned with EV

## Layer 3 — Adversarial Scenario
- [ ] Adversarial scenario generated (cut management's 3 most optimistic assumptions by 20-30%)
- [ ] Valuation bridge: management target → our fair value
- [ ] Upgrade and downgrade trigger conditions listed
