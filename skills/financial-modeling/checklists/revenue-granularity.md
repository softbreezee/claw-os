# Revenue Granularity Validation

- [ ] Each hardware line identified by Geography + Channel
- [ ] Each service line has independent User/Pricing/Churn assumptions
- [ ] No single line > 30% of parent product line without sub-division
- [ ] All row sums = report-level Revenue
- [ ] CAGR derived from line-level growth assumptions, not aggregate numbers
- [ ] Customer-dimension model used when company is reseller AND top supplier > 30% of revenue
- [ ] Each supplier/platform has independent Account #, ARPU, Growth
- [ ] Supplier concentration calculated (Top 1, Top 3)
- [ ] If concentration > 50%, "supplier loss" sensitivity scenario added
