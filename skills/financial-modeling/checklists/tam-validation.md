# TAM Validation Checklist

## Data Quality
- [ ] Layer 1 data from official sources (World Bank / IMF / National Statistics)
- [ ] Layer 2 IT spending % cross-checked with Gartner/IDC
- [ ] Layer 3 penetration rates have historical trend support (not guesswork)
- [ ] Layer 4 limitations explicitly stated
- [ ] Layer 5 SOM vs actual revenue variance < 10%

## Consistency
- [ ] TAM CAGR vs industry report CAGR variance < 5pp
- [ ] All sources and dates annotated
- [ ] Competitor SOM sum < 100% of TAM (otherwise TAM underestimated)

## Decision Rules
- SOM/SAM > 30% → Red flag: limited growth space
- TAM CAGR < Revenue CAGR → Red flag: unsustainable company growth
- TAM-derived Revenue vs Model Revenue variance > 15% → Yellow flag: explain divergence
