# Investment Thesis Template (Hedge Fund Track)

> Without a clear thesis, you don't have a position — you have an opinion.

## Layer 0: Five Required Fields

### 1. Core Conviction

> I believe [Company X]'s [Core Variable Y] will [Change A, different from consensus] within [Time Z]

**Requirements**:
- Core Variable Y must be a leading indicator in the financial model that affects price
- Change A must have clear opposition vs. consensus (no ambiguity)
- Time Z must be specific (no "long-term")

### 2. Consensus vs My View

| Dimension | Market Consensus | My Thesis | Evidence |
|-----------|-----------------|----------|---------|
| Core Variable | | | |
| Secondary Variable 1 | | | |
| Secondary Variable 2 | | | |

**Key Questions**:
- Where does consensus come from? (Sell-side research, forward guidance, historical mean?)
- How large is the delta? (>10% to be tradeable)
- When will the market re-price? (What is the catalyst?)

### 3. Catalyst

```
Prove event: [Q report date / Event date]
Key metric to watch: [Specific number / guidance]
Trigger threshold: If [metric] > or < [number], thesis is proven/falsified
Timeline: [When does market re-price?]
```

### 4. Asymmetry — Expected Value

| Scenario | Probability | Target Price | Return vs Current | Contribution |
|----------|-----------|-------------|-------------------|-------------|
| Bull (thesis correct) | __% | $__ | +__% | __% |
| Base | __% | $__ | ±__% | __% |
| Bear (thesis wrong) | __% | $__ | -__% | __% |
| **Expected Value** | - | - | **___%** | - |

**Quality gates**: EV > 5% to trade; Upside/Downside Ratio > 2.0x preferred; Asymmetry index > 1.0x required.

### 5. Stop-Loss Conditions

```
Hard stop: If [observable metric crosses threshold], exit position
Soft stop: If [thesis deteriorates], review position
Time stop: If thesis not proven by [date], exit
```

## Constraint Rules
1. Layer 1 research must directly address Core Variable Y
2. After Layer 1, publish Thesis Validation Statement (proven / modified / falsified)
3. If Layer 0 cannot be completed, Layer 1 goal becomes "find a tradeable thesis"
