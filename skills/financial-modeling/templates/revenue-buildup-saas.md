# Revenue Build-up Template: SaaS / Subscription

## Revenue Architecture
```
Revenue = Σ(Service Line) [User Base × ARPU × (1 - Churn)]
```

## Template

| Service Line | Metric | Year 1 | Year 2 | Year 3 | Year 4 | Year 5 |
|-------------|--------|--------|--------|--------|--------|--------|
| **Line A** | | | | | | |
| Beginning Users | # | | | | | |
| New Users Added | # | | | | | |
| Churned Users | # | | | | | |
| Ending Users | # | | | | | |
| ARPU ($/user/yr) | $ | | | | | |
| Churn Rate | % | | | | | |
| Revenue | $ | | | | | |
| **Line B** | | | | | | |
| _(repeat structure)_ | | | | | | |
| **Total Revenue** | $ | | | | | |

## Required Assumptions (per service line)
- [ ] Independent user count with separate growth rate
- [ ] Independent ARPU with pricing trend
- [ ] Independent churn rate with improvement trajectory
- [ ] CAC Payback period calculated (if applicable)
- [ ] LTV/CAC ratio > 3.0x validated

## Validation
- [ ] No single service line > 30% of total without further split
- [ ] All line-level revenue sums = report-level total
- [ ] CAGR derived from line-level growth, not aggregate
